АВТОГЕНЕРАЦИЯ - БЫСТРЫЙ ЗАПУСК

АВТОУСТАНОВКА ИЗ GITHUB (рекомендуется)

1. Скачайте INSTALL_FROM_GITHUB.cmd из последнего релиза:
   https://github.com/evosent/watch-automation/releases/latest
2. Дважды нажмите INSTALL_FROM_GITHUB.cmd.
3. Установщик загрузит программу и референсы, затем один раз скачает фототеку часов
   (около 2,1 ГБ), если папки input-watches-images ещё нет. На диске потребуется
   около 5 ГБ свободного места для скачивания и распаковки.
4. Скрипт установит Node.js LTS и Chrome for Testing, проверит файлы и запустит программу.
5. PDF-инструкция откроется отдельно; на рабочем столе появится ярлык
   «Автогенерация — профиль».

ПЕРВЫЙ ЗАПУСК РАСШИРЕНИЯ

1. В открывшемся отдельном окне Chrome for Testing войдите в ChatGPT.
2. Откройте панель расширения «Автогенерация» через значок расширений Chrome.
3. В блоке «Референсы» выберите вложенную папку input-ref-images.
4. В блоке «Фото часов» выберите вложенную папку input-watches-images.
5. Проверьте фильтры и количество фото за запуск, затем нажмите СТАРТ.

Если комплект уже распакован, запустите его внутренний INSTALL_WatchAutomation.cmd.
Для обычного запуска без установки используйте START_AUTOGENERATION.cmd.

ПОСЛЕДУЮЩИЕ ЗАПУСКИ

Используйте ярлык «Автогенерация — профиль» на рабочем столе. Он вызывает единый
launcher, запускает watcher и открывает свежий Chrome for Testing с сохранённым
профилем, ChatGPT и подключённым расширением.
Командный файл для обычного запуска остаётся доступен в папке комплекта.

Расширение загружается автоматически из комплекта. Для этого используется отдельный
Chrome for Testing и профиль %LOCALAPPDATA%\WatchAutomation\ChromeProfile.
Обычный пользовательский Chrome и его вкладки не затрагиваются.
При запуске обновлённого комплекта launcher сам завершает только старые процессы
Chrome for Testing этого automation-профиля. Обычный Chrome не затрагивается.

Папки уже заполнены текущими референсами и фотографиями часов.
Обычное обновление через вкладку «Сервис» обновляет код, промпты и референсы.
Фототека часов остаётся на компьютере и повторно не скачивается. Чтобы заменить
входные данные, выберите свои папки через панель расширения. Память генераций хранится в Chrome.

Подробная инструкция находится в docs/WatchAutomation_Инструкция.pdf.
Технические сведения и локальные endpoints описаны в README.md.

Если Chrome уже использует отдельный профиль автоматизации, его данные находятся в:
%LOCALAPPDATA%\WatchAutomation\ChromeProfile
