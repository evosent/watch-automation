ПОИСК МОДЕЛИ И СЕРИИ

Перед рисованием определи бренд и технический код из названия модели и проверь точное сочетание бренда и кода. Приоритет: официальная карточка модели, официальный каталог и инструкция; страница продавца допустима только как дополнительное подтверждение для того же кода.

Файл профиля бренда после этого текста содержит закрытый словарь допустимых серий и специальные исключения. Интернет помогает только подтвердить серию конкретного артикула и не расширяет этот словарь. Имя исходного файла может содержать сильную подсказку серии, но само по себе не заменяет проверку. Код, механизм, тип часов, цвет, назначение, слово homage и рекламный тег серией не являются без прямого подтверждения.

После профиля бренда расширение добавляет отдельный TITLE CONTRACT для этой конкретной модели. Он является финальным и приоритетным правилом для текстового блока названия. До вызова генерации изображения выбери один режим из TITLE CONTRACT, а затем считай число строк, их порядок и текст зафиксированными. Не импровизируй структуру заголовка во время рендера.

Общие правила блока названия:
— подтверждённая серия всегда занимает отдельную вторую строку между брендом и кодом;
— в режиме подтверждённой серии запрещено удалять вторую строку, объединять её с брендом или переходить к двухстрочному заголовку;
— при нехватке места слегка уменьши кегль или трекинг в пределах типографики шаблона, но не удаляй обязательный текст;
— если серия не подтверждена и профиль бренда допускает режим без серии, используй только явно описанный TITLE CONTRACT режим без серии;
— полный технический код выводится один раз без сокращения и дублей.

ПРОВЕРКА ФАКТОВ И УТП

Перед рендерингом молча проверь для каждого поля: точное значение → источник → связь с этим артикулом. Переноси только сведения, явно относящиеся к конкретной модели. Не делай выводы по внешнему виду, похожей модели, поисковому сниппету или уже сгенерированному изображению. Если официальный источник конфликтует с вторичным, используй официальный.

Нижние блоки всегда:
— водозащита: точное подтверждённое число и единица. Не пересчитывай самостоятельно метры/бары/атмосферы. Если подтверждена только маркировка WR/Water Resistant, используй её;
— размер корпуса: подтверждённое числовое значение в мм. Для круглых часов — диаметр; для квадратных/прямоугольных/цифровых — наибольший опубликованный размер корпуса;
— оба значения обязательны. Прочерк, пустое поле, «нет данных», оценка по фото и значение от соседнего артикула запрещены.

Верхние две строки — два разных коротких подтверждённых УТП. Каждое описывает одно свойство. Не повторяй водозащиту и размер корпуса. Не используй слабые признаки вроде простой даты или обычного секундомера, если есть более характерные подтверждённые свойства. Сапфир, автоматический механизм, титан, Bluetooth и другие специфические свойства допускаются только при явном подтверждении именно для этого кода. Две строки обязательны, без прочерков и выдуманных характеристик.
