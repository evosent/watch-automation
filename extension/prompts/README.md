# Профили брендов

Файлы из `brands/` — компактные данные профиля, которые расширение добавляет к общему `Base Prompt v5.txt` перед каждой генерацией. Общая композиция и правила доказательности находятся в базовом файле; профиль хранит брендовые ограничения, источники и словарь допустимых названий, если он нужен конкретному бренду.

Референсы хранятся в `input-ref-images/brands/<бренд>/`:

- `1. Base.png` — брендовый шаблон карточки;
- `2. Base n Ozon.png`, `2. Ozon blind zones.png` или `2. Ozon blind zones 2.png` — универсальная маска слепых зон Ozon;
- общий `input-ref-images/3. Logo Black.png` — логотип магазина.

Поддерживается и вариант без промежуточной папки `brands/`: `input-ref-images/<бренд>/...`.

Имя бренда определяется по имени входной фотографии. При отсутствии брендового набора расширение использует старые плоские `1. Base.png` и `2. Base n Ozon.png` как резервные. Логотип магазина остаётся общим.

Перед генерацией модель ищет точную серию по полному названию и артикулу в интернете для брендов, у которых включён словарь серий.
Официальная карточка бренда, каталог и инструкция имеют приоритет. Найденная серия
нормализуется и сверяется с закрытым словарём профиля. В карточку попадает только
точное совпадение с этим словарём; интернет не может расширять словарь. Если совпадение
не подтверждено, профиль применяет собственную политику fallback. Для Pagani Design
поиск и вывод серии отключены: заголовок всегда состоит из строк `Pagani`, `Design`
и отдельной технической строки с полным PD-кодом. Сейчас fallback
`Classic` задан только для обычных неименованных моделей Casio после поиска. Для
остальных брендов включается режим без серии: первая строка блока названия остаётся
пустой, бренд переносится на позицию второй строки, код остаётся на фиксированной
третьей позиции. Имя файла служит подсказкой для поиска и само по себе серию не
подтверждает. Любая характеристика и число также требуют подтверждения именно для
этого артикула; визуальное сходство, соседняя модель и рекламный сниппет доказательством
не являются.


## TITLE CONTRACT (pipeline v6)

`Base Prompt v5.txt` больше не оставляет геометрию заголовка на свободное решение модели.
`prompt-profiles.js` после общего prompt и файла бренда добавляет последним блоком `TITLE CONTRACT` для конкретного артикула.
Он содержит бренд, полный технический код, допустимый кандидат серии из имени источника (если он есть), режим с подтверждённой серией и точный режим без серии.
После выбора режима число строк и их порядок считаются фиксированными. В режиме с серией строка 2 обязательна и не может быть удалена или объединена с брендом.

Режим `2 файла · шаблон + часы` является режимом по умолчанию. Отдельные Ozon-map и Watches World остаются доступны как совместимые режимы 3/4 inputs.
