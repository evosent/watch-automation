# Передача результатов между пользователями

В галерее нажмите «Передача результатов». Для экспорта выберите конкретный прогон или все сохранённые результаты, затем «Собрать и скачать архив». Программа берёт PNG из `WatchAutomation` в системной папке «Загрузки». Отсутствующие, изменённые и отклонённые изображения исключаются; отчёт перечисляет пропуски. Для большого набора выбирайте отдельные прогоны: предел одного архива — 1 ГБ, 5000 результатов, 64 МБ на файл.

На принимающем компьютере откройте тот же раздел, выберите ZIP и нажмите «Проверить архив». Отчёт покажет новые результаты, совпадения, другие версии и фотографии без спецификации. «Импортировать и объединить» установит фотографии в локальную `Загрузки/WatchAutomation/<категория>` и объединит записи с базой. Перед импортом завершите или сбросьте активный прогон. Для функции нужен актуальный локальный сервис; после обновления перезапустите приложение через `START_AUTOGENERATION.cmd`.

Результаты сопоставляются по каноническому ID модели и SHA-256 PNG. Повторная передача идемпотентна. Существующая локальная версия остаётся основной при конфликте; альтернативный PNG и его ревизия сохраняются. Ранее отклонённое совпадающее изображение сохраняет статус брака. Фото без готовой спецификации сохраняется с соответствующим промежуточным статусом. Если локальное исходное фото отличается по контрольной сумме, полученная ревизия сохраняется отдельно, а очередь локального исходника сохраняет своё состояние.

Архив содержит `manifest.json` с версией формата, датами, ID моделей/прогонов, профилями, идентичностью исходника, спецификациями и `images/<sha256>.png`. Настройки приложения, активные вкладки, данные входа в ChatGPT и абсолютные пути отправителя в архиве отсутствуют. Произвольные пути, лишние файлы, повторяющиеся записи, неподдерживаемые версии и повреждённые ZIP/PNG отклоняются до установки.

При импорте текущие файлы сохраняются; новые имена включают полную контрольную сумму. После проверки файлов каталог, ревизии и спецификации записываются одной транзакцией. Отдельный журнал сохраняет незавершённое слияние с памятью очереди и позволяет продолжить его после перезапуска. Пока журнал активен, запуск генерации и обновление расширения ожидают завершения импорта. Кнопка «Завершить импорт» повторяет установку и слияние. Временные распакованные фотографии удаляются после успешного слияния; рабочие PNG остаются в папке результатов.
