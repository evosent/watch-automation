# WatchAutomation 0.3.56

Исправлен импорт архивов результатов больше 1 ГБ. Единый предел импорта и экспорта составляет 4 294 967 294 байта — чуть меньше 4 ГБ.

- Выбор ZIP, загрузка в локальный сервис, проверка и распаковка используют общий предел.
- Экспорт учитывает заголовки ZIP и оглавление до начала сборки; файлы обрабатываются последовательно.
- Проверка запущенного сервиса обнаруживает старое ограничение и сообщает о необходимости полного перезапуска.
- Сохраняются ограничения 5000 результатов и 64 МБ на отдельный распакованный файл.

Для обновления завершите активный прогон, откройте настройки расширения и нажмите «Проверить и обновить». Дождитесь перезапуска приложения и затем повторите импорт. При сообщении о старом сервисе полностью перезапустите приложение через `START_AUTOGENERATION.cmd`.

Память генераций, готовые изображения и входные фотографии пользователя сохраняются. Пакет обновляет код, промпты и референсы.
