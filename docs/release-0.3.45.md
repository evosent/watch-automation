# WatchAutomation 0.3.45

## Статусы очереди после остановки

После окончательной остановки или сброса незавершённые попытки возвращаются в
«Не готово» и становятся доступными для нового запуска. Очищаются ошибки,
состояние отправки и ожидания, счётчики повторных попыток. Статус обновляется
также во вложенной записи соответствующей исходной фотографии.

Сохранённые результаты, PNG, история ревизий и очередь брака остаются на месте.
Ошибки предыдущего прогона сохраняются в его диагностике. Пауза сохраняет
состояние текущего прогона для продолжения.

Старые зависшие записи остановленной сессии очищаются при открытии расширения.
Очистка выполняется при отсутствии активного прогона; повторное выполнение
оставляет очищенные записи без изменений. Состав и нумерация частей сохраняются.
Прогресс относится к конкретному исходнику часов и учитывает его путь,
контрольную сумму и вариант качества.

## Проверка и обновление

243 автоматических теста проверяют работу приложения, включая очистку
остановленной сессии, защиту активного прогона, сохранение готовых результатов
и изоляцию вариантов исходных фотографий.

Обновление доступно через «Настройки» → обновление расширения. Пакет содержит
код, промпты и визуальные референсы. Память генераций и входные фотографии часов
в пакет обновления не включаются.
