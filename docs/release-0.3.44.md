# WatchAutomation 0.3.44

## Запуск и галерея

При запуске приложения открывается стартовая страница ChatGPT. Галерея открывается
кнопкой «Результаты» и показывает сохранённые изображения и характеристики.
Открытие и обновление галереи больше не создают чаты для поиска незавершённых
спецификаций. Удалены также повторные исторические проверки после обновления
расширения; сохранённые задания такого типа отменяются.

Проверка спецификации в текущем прогоне сохраняется, включая наблюдение за уже
отправленным ответом и ограниченный срок ожидания. Сохранённые PNG, ревизии,
история и прогресс очередей остаются на месте.

Первый запуск фонового обработчика в новой сессии браузера сначала сверяет
сохранённый прогон. Обычное пробуждение фонового обработчика в той же сессии
продолжает его работу. Это устраняет конкуренцию восстановления сессии с
повторным запуском отправки подготовленных промптов.

## Объединённые изменения

Основная ветка включает исходный интерфейс патча 0.3.43, исправления зависаний
подготовки и загрузки файлов, учёт времени активной работы, импорт и экспорт
результатов с изображениями и исправления механизма обновления.

## Установка и обновление

Установщик получает актуальную версию из последнего стабильного GitHub Release.
Для установленного приложения используется «Настройки» → обновление расширения.
Обновляющий пакет содержит код, промпты и визуальные референсы. Входные фотографии
часов и пользовательская память генераций в него не включаются.
