# Аудит и новая схема промпта карточек

Дата аудита: 2026-09-14.

## Что проверено

Проверен текст из вложенного файла `pasted-text.txt` (общий промпт, строки 1–576,
профиль Longines, строки 578–584, и динамический блок контроля, строки 585–602).
Проверена фактическая сборка расширения: `sidepanel.js` загружает общий файл,
`service-worker.js` выбирает профиль и брендовые референсы, а `content-script.js`
прикрепляет изображения в порядке `@1`, `@2`, `@3`, `@4`.

## Новая архитектура

`extension/Base Prompt v4.txt` и корневая копия синхронизированы. Общий текст теперь
содержит только неизменяемую механику задачи: роли `@1–@4`, границы редактирования,
поиск серии, доказательность характеристик, композицию и финальную проверку.
Объём общего текста: 86 строк и около 8,5 КБ вместо 583 строк и примерно 50 КБ.

`extension/prompts/brands/*.txt` содержат закрытые словари серий, источники и
исключения конкретного бренда. Общие правила из них удалены.

`prompt-profiles.js` добавляет короткий динамический блок для текущей модели. Если
загруженный файл профиля уже содержит закрытый словарь, список не дублируется. Для
самостоятельного вызова `buildBrandInstruction()` список остаётся доступным.

## Правило доказательности УТП

Характеристика печатается только при явном упоминании точного артикула в источнике.
Внешний вид часов, типичная спецификация бренда, соседний артикул, сниппет поиска,
рекламный тег и сгенерированная картинка доказательством не являются. При конфликте
источников выигрывает официальный источник. Значение без подтверждения остаётся
пустым; это относится к сапфировому стеклу, автоматике, титану, Bluetooth, диаметру,
водозащите и любому другому числу или свойству.

Для серии поиск в интернете сохраняется: модель ищет кандидата по полному коду,
затем принимает его только при точном совпадении с локальным словарём бренда.
Интернет не может добавить новую серию. Для Casio `Classic` остаётся единственным
профильным fallback и срабатывает после поиска только для обычной неименованной
модели.
