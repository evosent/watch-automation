# Перенос интерфейса 0.3.43

Основа: интерфейс из WatchAutomation_PATCH_0.3.43/replace-in-project.
Перед переносом сохранена версия ff3fd3c; работа выполнена в codex/full-patch-interface.

## Перенесено

- sidepanel.html: исходная разметка, расположение разделов и кнопок.
- sidepanel.css: полностью исходный файл, без слоя переопределений прежнего интерфейса.
- sidepanel.js: отображение плейлистов, выбор части, дерево бренд/категория, компактные подписи и прогресс.
- playlist-ui-utils.js: исходный вычислитель прогресса представления, сохраняющий состав и подписи частей.
- gallery.html/css/js: исходный интерфейс результатов, фильтров и просмотра спецификации.

## Сохранено из актуальной версии

- Учёт активного времени прогона; паузы и остановка замораживают таймер и среднюю скорость.
- Обработчики восстановления, остановки/сброса и текущий протокол обновления.
- Полная передача результатов через ZIP, включая объединение прогресса.
- Проверка точной части, её подписи и наличия доступных моделей перед запуском.
- Сброс устаревшей предварительной проверки после изменения параметров.
- Импорт прежних названий разделов очереди/настройки из локального состояния интерфейса.

Файлы сервисного работника, адаптера ChatGPT, хранилища и обработчика архивов при этом переносе не заменялись.
Данные пользователя не очищались.

Дополнения к исходной разметке: кнопка «Передать результаты · ZIP» в «Настройки → История и данные»,
сохранённое окно передачи в галерее, подпись «Фото за запуск», исходный режим двух референсов.
В галерею можно перейти непосредственно к передаче по gallery.html#transfer.

сохранение задания при просмотре другой части на паузе, замороженный таймер и среднее время,
разделы настроек, переход к передаче результатов и просмотр PNG со спецификацией.
